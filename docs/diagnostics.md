# 本地诊断与回放

这些命令只适用于你有权处理的媒体。诊断回放在本机解码，不发送音频，不调用模型或 AI 服务。报告不包含原文和音频采样；故障注入是明确标记的模拟，不代表硬件、转写准确率或真实服务已经验收。报告路径必须是不存在的新文件。

保存状态检查包含在线说话人检查点是否存在、是否收尾、是否记录未完成原因、输入终点和区间数量；不输出说话人姓名或原因正文。它只反映磁盘上最后保存的状态，不连接正在运行的任务。

对于新版录制报告，状态检查还显示已保存的采集计数、回读 P95 上界和最终音频订阅队列统计；旧报告缺失的字段为 `null`。订阅快照不是消费者完成状态，订阅未送达帧也不等于录制媒体丢失。输出对订阅角色和来源使用固定枚举，最多列出 32 项，不输出原始警告正文、设备名或路径。

暂停边界音频丢弃计数只统计录制线程队列中的块及 48 kHz 立体声采样帧；采集端和路由切换丢弃不包含在内。旧报告缺少计数时显示 `null`，不能按零处理。

性能历史最多保存最近 1800 个采样；新报告记录丢弃的早期采样数，状态检查分别显示保留数和丢弃数。旧报告没有丢弃计数时显示未知，不能据此认为历史完整。

逐字稿的运行诊断区分标点请求与实际处理、句段复核是否请求/安排以及记录的运行状态；已有逐块归一化和同步识别耗时时显示数字摘要。旧数据缺失时保持未知，耗时不包括解码、异步复核和 GPU 完成时间，也不等于端到端延迟。

SenseVoice 新运行记录实际传给后端的语言模式；状态诊断不把模式或旧版语言字段当作已识别语言。其他识别路径未记录语言模式时显示未知。

SenseVoice 新运行还记录集成向后端请求了 ITN；诊断及界面不把请求开关当作文本规范化效果已经验证。其他路径及旧运行未记录时显示未知。

逐字稿状态同时列出保存的完成标志和按当前规则计算的完整状态，以及已确认、未确认、空文本、无可播放时间和重复句段 ID 数量。原始 token 或词对齐证据的总数与通过当前文本和已保存来源校验的数量分开；状态检查不会读取或哈希当前媒体，不能证明它现在仍可用于播放。

开发版命令行需要单独启用隔离身份；否则普通命令行构建使用正式版配置和模型路径：

```sh
CARGO_TARGET_DIR=target/opencap-dev cargo build -p opencap-asr --features dev-profile --locked
target/opencap-dev/debug/opencap-transcribe status --meeting /path/to/test-copy/meeting
target/opencap-dev/debug/opencap-transcribe diagnose-replay /path/to/authorized-test.wav --report /path/to/new-report.json --fault drop-packet
```

`status` 只读取所选开发版配置、模型文件存在与大小，以及可选会议的已保存计数和状态；它没有连接运行中的应用进程。它不输出路径、正文或凭据。模型存在不等于内容已校验或模型质量已验证。

`diagnose-replay` 支持 `none`、`silence`、`drop-packet`、`speaker-timeout`、`minutes-timeout`、`late-speaker-result`、`export-failure`。其中纪要超时使用真实的本地请求状态与放弃/重试逻辑；导出失败在报告旁的独立临时目录内阻断 Word 路径并检查已保存正文。测试目录在完成后删除，不接触原始会议文件。

重放报告的 `gaps_ms` 是按解码包到达顺序观察到的间隔和模拟丢包，后到的乱序或重叠包可能覆盖先前记录的间隔，不能当作最终媒体缺失区间。`out_of_order_packets` 记录起始时间相对前一包倒退的次数；间隔最多列出 4096 条，另有总数与截断标记。

真实设备排查仍应分别使用系统测试音、麦克风输入和 `opencap-bench audio-probe`，并检查录制报告的音频来源状态及丢包。扬声器串音、设备路由和模型识别错误需要分别验证。

如果录制视频已保存但独立音频导出失败，可在会议库中对受管理的录屏选择“导出独立音频”，也可以使用本地构建的 `opencap-bench export-audio <视频路径> <新音频路径>`。输出路径必须不存在；导出前后会核对源文件，失败时提示保留的暂存文件位置。应用内操作支持请求取消，但需等待当前 FFmpeg 调用返回。入口和命令均尚待集中测试。

macOS 麦克风探针启动时核对实际设备，并在运行中检查采集状态和默认设备变化；系统声音探针覆盖所有输出设备，不支持选择单个输出设备。设备核对依赖平台接口和周期检查，尚需实机验证。

OpenCap v2.0，应用与安装包版本为 **2.0.0**。

### 录制性能和体验

- 优化录制工作线程的唤醒方式、编码图像缓冲复用与 Windows 采集前限速；低占用设置在自动编码时优先尝试 H.264，并提供更快的软件编码选项。
- Windows 新增默认关闭的「异步采集（实验）」选项。初始化失败时回退原采集方式；运行中出现严重错误时结束录制并保留已完成内容。录制报告补充实际采集路径、回读数据量与等待统计。
- 一键降低占用会同时调整帧率、预览和实时转录，设置可分别恢复。10 FPS 可以减少部分工作，但不能保证旧电脑的鼠标不卡，也会降低动态画面的流畅度。新 Windows 采集路径和旧 i5 上的实际性能仍需设备实测。
- 改善长逐字稿的显示和滚动、处理任务的进度与卡住提示；macOS 打包时保留旧包，并避免覆盖正在运行的应用。

### 语音转录

- 实时识别可选择轻量、标准、增强 Zipformer，或使用所选文件模型逐句识别；文件转录和可选的句末二遍复核支持 SenseVoice、Paraformer 轻量中英和 Paraformer 标准中英。
- 增加可选的本地中英标点恢复模型：实时稿定期补标点，句末定稿和二遍复核结果再次处理。请在「设置 → 识别模型」下载模型；未安装时仅补基本句末标点。标点是预测结果，可能需要人工调整。
- 二遍识别保留逐句流式原稿、复核稿、处理状态和耗时；模型积压或失败时保留原稿。录制结束后可在逐字稿中选择原稿或复核稿，也可用其他文件模型另存重转。
- 说话人区分目前仍为会后分析；实时说话人区分和云端语音识别尚未实现。模型按需下载到本机，不包含在安装包中；本地识别不会上传音视频。

### 下载与兼容性

| 平台 | 安装包 | 要求 |
| --- | --- | --- |
| Windows | `OpenCap-2.0.0-windows-x64.zip` | x64；完整解压后运行 `OpenCap/opencap.exe` |
| Mac Apple Silicon | `OpenCap-2.0.0-macos-arm64.zip` | 最低系统版本以本次 Release 验证信息为准 |
| Mac Intel | `OpenCap-2.0.0-macos-x64.zip` | 最低系统版本以本次 Release 验证信息为准 |
| Linux / 统信 UOS | `OpenCap-2.0.0-linux-x64.deb` 或 `OpenCap-2.0.0-linux-x64.tar.gz` | x86_64、glibc 2.28+；便携包运行 `OpenCap/AppRun` |

Mac 包为临时签名，未公证；升级后系统可能需要重新确认录屏权限。Linux 屏幕采集需要 X11，声音需要 PulseAudio 或 PipeWire-Pulse；Wayland 屏幕采集尚未实现。真实设备、驱动、说话人区分准确率及录屏功耗请以实测为准。

### 验证与来源

本机已运行工作区测试、严格 Clippy、已安装识别模型的合成语音回归和标点恢复检查；这些测试不能代替目标 Windows 设备及真实会议录音的验证。三端发布包由 `v2.0` 标签触发 GitHub Actions 构建并校验，通过后提供 `SHA256SUMS` 和 `build-validation.json`。

第三方依赖与许可证说明见 [THIRD_PARTY.md](https://github.com/NOBB2333/meeting_summary/blob/v2.0/THIRD_PARTY.md)。安装包不包含用户录音、文档、配置、密钥或语音模型。

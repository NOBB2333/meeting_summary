OpenCap v1.2，应用与安装包版本统一为 **1.2.0**。

### 本次更新

- 统一会议标识，修复一场会议因媒体路径与文稿路径不同而重复出现；兼容旧索引，不搬移原录音。
- 说话人分析结果与文件导出解耦。Word 被占用等导出失败时仍显示并保留结果，列出未同步文件，支持直接重试。
- 支持本场姓名和主动登记的本地声纹记忆。后续会后分析尝试匹配已保存姓名；短发言、重叠或不确定匹配保留编号，支持忘记声音。
- AI 纪要改为左侧持续对话、右侧文档预览；支持拖动分隔线、收起预览、版本卡片、历史恢复与手动编辑。窄窗口可切换主面板，输入框固定在底部。
- 逐字稿增加中文搜索、命中高亮、上下定位、原文拖选、逐段与全文复制，保持长稿虚拟列表和历史阅读位置。
- TXT 改为应用内只读预览，支持选择、复制和搜索；Windows 外部文件关联改在独立子进程执行，避免文件处理器阻塞主界面。
- 文件路径收进“文件位置”，减少顶部占用；右侧文档区可直接预览逐字稿和笔记 TXT。
- 麦克风降噪增加停顿保持与平滑释放，降低额外门限衰减；修正初始化缓冲零值影响噪声估计和自动增益的问题。

### 使用说明与边界

说话人仍在会后分析。点击“保存并记住声音”才登记到本机，需至少 3 秒独立发言；旧逐字稿需重新分析提取声纹。声纹匹配需要核对，不代表身份验证；不同设备和真实远场会议的准确率仍需实机测试。已生成的 AI 正文不会因姓名变更自动改写，可在对话中要求更新。

TXT 在应用内打开，Windows 主进程退出问题采用预览与进程隔离处理；尚未在用户原 Windows 环境复现并完成崩溃回测。降噪突变也可能涉及设备和系统增强，建议用同一录音环境对照开关确认。

### 下载

| 平台 | 安装包 | 要求 |
| --- | --- | --- |
| Windows | `OpenCap-windows-x64.zip` | x64；完整解压后运行 `OpenCap/opencap.exe` |
| Mac Apple Silicon | `OpenCap-macos-arm64.zip` | 以 Release 验证信息中的最低系统版本为准 |
| Mac Intel | `OpenCap-macos-x64.zip` | 以 Release 验证信息中的最低系统版本为准 |
| Linux / 统信 UOS | `OpenCap-linux-x64.deb` 或 `OpenCap-linux-x64.tar.gz` | x86_64、glibc 2.28+；便携包运行 `OpenCap/AppRun` |

Mac 包为临时签名，未公证；升级后系统可能需要重新确认录屏权限。Linux 屏幕采集需要 X11，声音需要 PulseAudio 或 PipeWire-Pulse，Wayland 采集暂未实现。真实 UOS 设备与驱动性能尚未实机验收。

### 验证

发布前本机通过 81 项工作区回归、严格 Clippy，以及真实已安装模型的合成声纹登记和匹配验证（4 组、512 维）。macOS 原生界面已验证中文搜索高亮、拖选复制、TXT 预览、窄窗切换和分栏拖动。这些验证不等于真实会议识人准确率测试。

三端发布包由同一提交的 GitHub Actions 重新构建，发布页提供构建链接。`SHA256SUMS` 提供校验值，`build-validation.json` 记录提交、安装包版本、系统要求与构建来源。

第三方依赖与许可证说明见 [THIRD_PARTY.md](https://github.com/NOBB2333/meeting_summary/blob/v1.2/THIRD_PARTY.md)。安装包不包含用户录音、文档、配置、密钥或语音模型。

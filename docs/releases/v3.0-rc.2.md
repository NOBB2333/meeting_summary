# OpenCap v3.0 RC2

应用和安装包的数字版本为 **3.0.0**。`v3.0-rc.2` 是预发布候选版本，不替代稳定版。

## 本版重点

- 重新整理录制工作台：预览区域可随窗口和侧栏伸缩；声音来源、电平检测、语音识别与 AI 设置集中在配置区。实时逐字稿与实时纪要在下方独立查看。
- 电平检测可在录制前或录制中开关；关闭时跳过电平统计，录制音频和录制状态检查继续运行。应用窗口选择器的滚动与外层工作区隔离。
- 设置页不再显示占据大量空间的录制进度条；会议库的缺失文件和转录状态使用紧凑提示。录制中可以只读查看其他会议的逐字稿，当前录制和转写继续运行；回放仍需先结束录制。
- 调整会议逐字稿、媒体、笔记与 AI 纪要工作区；长文本在有界区域内滚动，AI 对话与文档分别保留操作空间。
- 实时纪要为主动开启的功能：首次通常在累计 1–2 分钟后整理，后续至少间隔 2 分钟，仅有新内容或待复核内容时请求，优先等稳定句段停顿，结束后补齐。停顿是启发式条件，不代表系统已识别出真实话题边界。
- 录制底栏显示本场实时纪要请求中服务实际报告的输入与输出 Token；服务没有报告时会注明。该数值不包含其他 AI 任务，也不是费用账单。
- 本地流式语音识别、句段复核、媒体播放及会议库等 3.0 能力延续 RC1。在线说话人是默认关闭的实验功能，需要可信原生库和匹配模型，匿名标签可能变化；不保证在所有电脑上实时或准确。

## 验证范围

本版本的 GitHub Actions 对 Windows x64、macOS Apple Silicon/Intel 和 Linux x64 分别构建、测试并验证安装包；仅在平台构建全部成功后发布。此前 macOS arm64 曾使用真实会议录音验证文件转录、媒体播放与 AI 纪要。当前轮次的具体本机检查结果见提交及运行记录；Windows/Linux 实机、低配电脑、120 分钟会议及在线说话人的真实效果仍需进一步验证。

## 安装包

| 平台 | 文件 |
| --- | --- |
| Windows x64 | `OpenCap-3.0.0-windows-x64.zip` |
| macOS Apple Silicon | `OpenCap-3.0.0-macos-arm64.zip` |
| macOS Intel | `OpenCap-3.0.0-macos-x64.zip` |
| Linux x64 / 统信 UOS | `OpenCap-3.0.0-linux-x64.deb` 或 `OpenCap-3.0.0-linux-x64.tar.gz` |

安装包不包含用户录音、配置、密钥或语音模型。第三方依赖与许可证见 [THIRD_PARTY.md](https://github.com/NOBB2333/meeting_summary/blob/v3.0-rc.2/THIRD_PARTY.md)。
